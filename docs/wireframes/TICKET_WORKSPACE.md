# Ticket Workspace Wireframe

Desktop layout:

```text
┌───────────────┬─────────────────────────────────────┬──────────────────────┐
│ Saved queue   │ Ticket conversation                 │ Client context       │
│               │                                     │                      │
│ TKT-000812    │ Subject / state / assignment        │ Client               │
│ TKT-000813    │                                     │ Contact              │
│ TKT-000814    │ Customer + technician messages      │ Location             │
│ ...           │ Internal notes visually distinct    │ Device               │
│               │                                     │ Current RMM alerts   │
│               │ Reply / Internal Note composer      │ Related tickets      │
└───────────────┴─────────────────────────────────────┴──────────────────────┘
```

Principle: a technician should be able to triage, investigate context, communicate, assign, and change status without leaving the workspace.
